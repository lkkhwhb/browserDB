Getting Started

Create a database instance and define a typed collection. All operations are asynchronous.

typescript
import { BrowserDB } from "@lkkhwhb/browserdb";

interface User { name: string; age: number; }

const db = new BrowserDB();
const users = db.collection<User>("users");

// Insert a document — a UUID is generated if _id is not provided
const doc = await users.insertOne({ name: "Alice", age: 30 });
console.log(doc._id);

Collection API

insertOne

insertOne(doc: T, options?: InsertOptions): Promise<WithId<T>>
Inserts a single document. Set options.ttlMs to auto‑expire. Throws DuplicateKeyError if _id exists.
typescript
await users.insertOne({ name: "Bob", age: 22 }, { ttlMs: 86400000 }); // expires in 24h

insertMany

insertMany(docs: T[], options?: InsertOptions): Promise<WithId<T>[]>
Inserts multiple documents atomically. Detects duplicates within the batch and across storage.
typescript
await users.insertMany([
    { name: "Charlie", age: 28 },
    { name: "Dana", age: 35 }
]);

find

find(filter?: Filter<T>, options?: FindOptions<T>): Promise<WithId<T>[]>
Returns all documents matching the filter. Supports sort, skip, limit, and projection.
typescript
const adults = await users.find({ age: { $gte: 18 } }, {
    sort: { age: -1 },
    skip: 0,
    limit: 10,
    projection: { name: 1 }
});

findOne

findOne(filter: Filter<T>, options?: FindOptions<T>): Promise<WithId<T> | null>
Returns the first matching document or null.
typescript
const user = await users.findOne({ name: "Alice" });

updateOne

updateOne(filter: Filter<T>, update: Update<T>): Promise<{ matched: boolean; modified: boolean }>
Applies update operators to the first matching document.
typescript
await users.updateOne(
    { name: "Alice" },
    { $set: { age: 31 }, $inc: { visits: 1 } }
);

replaceOne

replaceOne(filter: Filter<T>, replacement: T): Promise<{ matched: boolean; modified: boolean }>
Replaces the entire document. Preserves the original __expiresAt (TTL) if present.
typescript
await users.replaceOne({ name: "Alice" }, { name: "Alicia", age: 32 });

deleteOne

deleteOne(filter: Filter<T>): Promise<{ deletedCount: number }>
Deletes the first matching document.
typescript
await users.deleteOne({ name: "Bob" });

count

count(): Promise<number>
Returns the number of documents in the collection.

clear

clear(): Promise<void>
Removes all documents from the collection.

Query Syntax

Filters are plain objects. Operators are prefixed with $. Deep equality uses a recursive comparison (handles undefined correctly).

OperatorDescription
$eqDeep equality
$neNot equal
$gtGreater than (string or number)
$gteGreater than or equal
$ltLess than
$lteLess than or equal
$inValue is in a provided array
$ninValue is not in the array
typescript
const result = await users.find({
    age: { $gte: 18, $lte: 65 },
    name: { $ne: "Bob" }
});

Logical combinations:

typescript
await users.find({
    $and: [
        { age: { $gte: 18 } },
        { status: "active" }
    ]
});
await users.find({
    $or: [
        { role: "admin" },
        { role: "moderator" }
    ]
});

Nested object values are compared with deepEqual, so { address: { city: "NY" } } works correctly.

Update Operators

OperatorDescription
$setSets the value of a field (nested paths not supported)
$incIncrements a numeric field (throws if non‑numeric)
$unsetRemoves a field
$pushAppends to an array; creates the array if missing
$pullRemoves all matching elements from an array (uses deepEqual for objects)
typescript
await users.updateOne({ name: "Alice" }, {
    $set: { status: "premium" },
    $inc: { points: 10 },
    $unset: { tempToken: 1 },
    $push: { tags: "vip" },
    $pull: { tags: "old" }
});

Reactive Subscriptions

Subscribe to a filter and receive updates whenever matching documents change (insert, update, delete, TTL expiry). The callback fires immediately with the current result.

typescript
const unsubscribe = users.subscribe(
    { status: "active" },
    (activeUsers) => {
        console.log(activeUsers);
    }
);

// Later, clean up
unsubscribe();
Batch‑aware: If a subscription is created while a transaction is in progress, the initial callback is delayed until the batch commits, preventing inconsistent reads.

Cross‑tab synchronization works automatically via the storage event (localStorage) or BroadcastChannel (IndexedDB).

Transactions

Wrap a group of writes across one or more collections in an atomic transaction. If any commit fails, all collections are rolled back to their pre‑transaction state.

typescript
await db.transaction(async () => {
    await users.insertOne({ name: "Eve" });
    await orders.deleteOne({ userId: "xyz" });
    // If either fails, both are rolled back
});
Transactions are not ACID, but they provide a strong safety net using in‑memory snapshots.

Middleware Hooks

Register synchronous or asynchronous callbacks to intercept data mutations.

HookSignature
beforeInsert(doc: T) => T | Promise<T>
afterInsert(doc: WithId<T>) => void | Promise<void>
beforeUpdate(doc: WithId<T>) => WithId<T> | Promise<WithId<T>>
afterUpdate(doc: WithId<T>) => void | Promise<void>
beforeDelete(doc: WithId<T>) => void | Promise<void>
afterDelete(doc: WithId<T>) => void | Promise<void>
typescript
users.beforeInsert(async (doc) => {
    doc.createdAt = new Date().toISOString();
    return doc;
});
users.afterUpdate((doc) => {
    console.log(`Updated user ${doc._id}`);
});

Schema Validation

Define a $jsonSchema validator that enforces types, required fields, and numeric bounds. Invalid writes throw ValidationError.

typescript
users.setValidator({
    $jsonSchema: {
        bsonType: "object",
        required: ["name", "age"],
        properties: {
            name: { bsonType: "string" },
            age: { bsonType: "number", minimum: 0 }
        }
    }
});

Lifecycle Management

collection.close(): void
Closes underlying IndexedDB connections and broadcast channels. Does not delete data.
collection.destroy(): Promise<void>
Calls close() and permanently deletes all persistent data for the collection (including metadata).
typescript
// Gracefully release resources
users.close();

// Completely remove collection data
await users.destroy();

Database API

MethodSignatureDescription
collection<T>(name: string, options?: CollectionOptions): Collection<T>Creates or retrieves a typed collection.
has(name: string): booleanReturns true if the collection exists (including IndexedDB‑backed).
dropCollection(name: string): Promise<void>Permanently removes the collection and all its data.
clear(): Promise<void>Removes all BrowserDB collections and data from all backends.
stats(): Promise<DatabaseStats>Returns storage usage and collection counts.
storage.info(): Promise<StorageInfo>Provides browser‑level storage estimates.
typescript
const exists = db.has("users");
await db.dropCollection("users");
await db.clear();
const stats = await db.stats();

Error Handling

ErrorWhen
DatabaseErrorGeneral storage failure or missing browser APIs
QuotaExceededErrorlocalStorage quota exhausted and migration/eviction failed
DataCorruptionErrorStored data cannot be parsed
DuplicateKeyErrorInserting a document with an existing _id
ValidationErrorDocument fails $jsonSchema validation
typescript
try {
    await users.insertOne({ _id: "dup", name: "Test" });
} catch (e) {
    if (e instanceof DuplicateKeyError) {
        console.error("Duplicate ID");
    }
}

React Integration

tsx
import { useState, useEffect } from "react";
import { BrowserDB, WithId } from "@lkkhwhb/browserdb";

const db = new BrowserDB();
const tasks = db.collection<Task>("tasks");

export function TaskList() {
    const [items, setItems] = useState<WithId<Task>[]>([]);
    useEffect(() => tasks.subscribe({}, setItems), []);
    // ... render
}

Limitations

Storage quota: While the hybrid engine migrates to IndexedDB when pressured, forced localStorage‑only mode may throw QuotaExceededError if no eviction policy is set.

Data is serialised as JSON, so some JavaScript types are not preserved:

TypeBehaviour
DateStored as ISO 8601 string; comparison is string‑based
Map / SetSerialised as empty object {}
BigIntThrows TypeError
undefinedFields with undefined are omitted; use null instead
FunctionStripped
